# case-003 findings — 审计对照组缺失四盲区

> 格式沿用：现象 → 处置 → 暴露次数 → 归层判定 → 终态。源：ACRS 实战 run 7 轮复盘（用户产出，2026-09-22）。

## F-001 同类对照硬规则（对照组缺失，最核心）

- **现象**：新增对外接口的落点与入出参形态（落 rpc 模块、裸 String 入参）与本仓既有 7 个对外接口
  （全在 export jar、BaseRequest 入参 + Response<T> 出参）完全相悖——grep 5 秒可得的事实，
  历轮 Gate 无一条点亮检查。所有 Gate 的检查对象都是"新增代码 vs 自己的 spec"，没有"新增 vs 既有同类"。
- **诊断**：B·规则真空。五类扫描"技术分叉（复用新建）"最接近，但只问复用/新建，未操作化为
  "MUST grep 既有同类落点+入出参形态"。
- **处置**（2026-09-22 落地，标 `case-003#F-001`）：acrs SKILL §三五类扫描段新增**同类对照**条款
  （设计前把既有同类形态设为默认锚点，差异点必说出理由）+ §六抽检新增第 6 条（无对照记录 = 审计不完整，
  打回）+ acrs-critic §三设计评审清单第 8 条。触发域限定"新增对外接口/新链路"，防膨胀成全仓考古。
- **机制优先问**："什么算同类/差异是否合理"需判断，不能全下沉为 lint/脚本，留 Convention。
- **暴露次数**：1（7 轮实战全漏检，代价真实：接口返工 + 鉴权不可用）。
- **闸门判定**：平台无关——任何仓库任何团队都犯 → Convention（skill 操作细则）。
- **终态**：**A·Closed**。登记观察：SOLO/FAST_TRACK 路靠 §六抽检点火，下一个真实新增接口 run 验证。

## F-002 框架咬合检查（"薄壳合格"掩盖框架契约）

- **现象**：web 实现类 32 行被判"薄壳无业务逻辑 ✓"放行，但鉴权切面要求入参有 BaseRequest 实例
  （@DoMethodAuth），裸 String 入参运行时永远过不了鉴权 PARAM_ERROR——硬约束藏在切面里，
  36 个绿单测全 mock 掉了，给足假安全感。R12 boot smoke 只抓"启动即崩"，鉴权失败是启动后行为，
  恰好落在两层之间。
- **诊断**：B·规则真空。§六假绿判据（fallback/断言过弱）不覆盖"框架契约被单测 mock"；boot smoke 不覆盖启动后路径。
- **处置**：acrs-critic §四代码评审清单第 7 条（薄壳类 MUST 追注解→切面/拦截器/序列化的运行时契约，
  "无业务逻辑 ✓"不算过）+ acrs SKILL §六抽检第 7 条。
- **暴露次数**：1（同 F-001 同案）。
- **闸门判定**：平台无关 → Convention（critic 清单 + 抽检细则）。
- **终态**：**A·Closed**。与 F-004 互补：本条管"审计动作"，F-004 管"证据不得夸大覆盖"。

## F-003 决策复验（决策留痕 ≠ 决策正确 + 总控自审降级）

- **现象**：javadoc 里"2026-09-18 拍板先落 rpc 模块"被历轮审计当作已 APPROVED 的既成决策沿用，
  无人复验其前提（"rpc 能当对外契约载体吗"grep 一下就是否定的）。且 rpc 落点本是总控自己在轮 1
  拍的板，后续 audit 同一上下文自我复核——§四独立性只约束了"派子 Agent 时不注入结论"，
  没约束"orchestrator 审计自己历史决策时降级为待核验项"。
- **诊断**：半 A 半 B。A 半：§九只认注入包内 status∈{APPROVED,FROZEN} 的 Artifact，代码注释
  从来不是合法注入产物——被当免检金牌属未遵守 + 表述太弱；B 半：自审历史决策降级条款确实缺失。
- **处置**：acrs SKILL §四评审独立性新增第 5 条（历史落点/形态类拍板一律降级为待核验项，
  前提 MUST 重 grep 复核；注释/TRD 拍板非 Artifact）+ acrs-critic §〇新增第 5 条（同义，评审侧）。
- **暴露次数**：1（轮 6 读到 export 注释仍按"拍板"沿用，TRD 还写了"迁移时只动包名"）。
- **闸门判定**：平台无关 → Convention。本案同时是 acrs-shared R5 ⚠️（CLI 单上下文弱隔离）
  预警风险的真实旁证，记档不另立条。
- **终态**：**A·Closed**。

## F-004 接地证据覆盖边界声明（full 档盲区）

- **现象**：接地证据 = 36 个单测全绿（full 模式 test=0），被隐式扩张为"鉴权路径已验证"——
  但单测把切面全 mock 掉了，test=0 只证"被测路径"，不证框架咬合。R12 scoped 档已有"范围说明"，
  full 档无任何边界声明义务。
- **诊断**：B·规则真空（full 档的证据语义缺边界声明）。
- **处置**：acrs-shared R12 新增**接地证据 MUST 附覆盖边界**条款（证据显式声明覆盖了什么/未覆盖什么，
  未覆盖框架路径列入待联调清单；禁止 test=0 隐式扩张）。机制优先问：优先在 Binding 侧 result 块
  schema 机制化（coverage_boundary 字段），平台无关层先落义务。
- **暴露次数**：1。
- **闸门判定**：平台无关 → Convention（acrs-shared R12 接地谱系补强）。
- **终态**：**A·Closed**。回链：acrs-shared R12（第 5 条 bullet）。
