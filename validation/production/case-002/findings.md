## F-001 七项机制吸收（已落地，A·Closed 回链）

- **现象**：fin-buddy 有 7 项已验证机制填补 ACRS 操作细节缺口，防的故障模式可观察、平台无关、落地成本≈0。
- **处置**（2026-09-22 落地，均标 `fin-buddy@5ecfd07`）：
  1. 归因环境须出示可复核证据否则按真实缺陷打回 → acrs-shared R12
  2. 绕过签名清单（skip 参数/`|| true` 吞错/删弱失败测试/缩范围绕红）= 假绿 → acrs-shared R12 + acrs SKILL §六
  3. 确认链落盘 + 交互预算（无记录的自我说服不放行；下游闸门复用不重问）→ acrs SKILL §三
  4. 收口复盘扫描（判 DONE 核对 ⑤，防回溯债）→ acrs SKILL §七
  5. 诊断先于修改（兑现失败 vs 规则真空 + 机制优先问）→ `validation/README.md`
  6. Harness 自身变更回归约束（固定模型版本/前后对比/禁凑数据）→ `validation/README.md`
  7. FEEDBACK 消化节奏触发器（防堆积腐烂）→ `assets/README.md`
- **暴露次数**：0（ACRS 侧预防性收编；fin-buddy 侧对应故障有真实记录）。
- **闸门判定**：全部平台无关；1-4 属接地/闸门操作化 → Convention（skill 层）；5-7 属体系自我演进协议 → validation/assets 文档层。**Core 测试：均不够 Core**（是已有不变量的操作化细则，非新不变量）。
- **终态**：**A·Closed**（逐条回链落地）。登记观察：下一个真实 case 验证各条款是否真实点火——从未触发的条款本身是挂账信号。

## F-002 四项挂账（带吸收触发器，不落地）

- **现象**：四项机制有价值但缺触发条件，现在收编 = 吸收性膨胀（违 P8"机制已被证明必要才进核心"）。
- **处置**：挂账台账化（`docs/coexistence-fin.md` §6），每项带明确触发器：
  1. 进化提案四态目录 → 活跃未消化条目 >20 再评估（现双通道管得住）
  2. SDD 章节级 frozen 版本号 → 出现"下游消费的冻结接口被上游改"类 finding ≥1
  3. 首批风格校准 → 有 Review 首过率数据后评估（当前无此数据）
  4. 确定性代码图（GENERATED/CURATED 分离）→ ≥2 项目出现"盲改未知影响面"类 finding；属工具层永不进规范
- **暴露次数**：0。
- **闸门判定**：挂账机制本身即闸门产物（防膨胀三问的应用）。
- **终态**：**挂账（Deferral）**——台账可查、触发器明确、不占规范。触发即转 F-001 式吸收流程。

## F-004 借鉴源自身的失败观察收编为警戒（最有价值的一条）

- **现象**：fin-buddy 进化管道设计完备（inbox→去重→三问→诊断→质疑→基准→人工→归档），但实地观察
  `evolution/inbox/` 堆积 **11 条、`applied/` 为 0**——机制设计了 ≠ 机制运转了；消化环节缺节奏触发器，管道退化为"换个地方堆积"。
- **根因**：纯事件驱动消化（等 Rule of Three 自然命中）+ 无人负责清账 → 收集与消化职责分离无闭环。
- **处置**：双落地——① 警戒原文写进 `validation/README.md`（诊断先于修改一节末尾）；② ACRS 侧对冲机制 = 判 DONE 核对 ⑤（每个真实 case 收口 MUST 扫未消化条目，逐条给终局或更新计数）+ `assets/README.md` 消化节奏触发器。
- **暴露次数**：1（fin-buddy 实地观察，非 ACRS 事故——ACRS 侧 case-000 的"六周回溯债"是其同源形态的独立旁证）。
- **闸门判定**：平台无关的机制失效模式 → Convention（消化协议细则）。
- **终态**：**A·Closed**。登记观察：ACRS 侧若出现 FEEDBACK/findings 活跃条目持续增长而收口扫描未清账 → 本条升级为事故 finding，转 B 路径。

## F-005 入库文档写本机绝对路径，破坏可移植性（用户提出）

- **现象**：case-002 README 引用 fin-buddy 用了本机绝对路径——换电脑路径失效，团队成员读到时无从定位，引用断裂。

- **处置**：① 本 case README 改可移植引用（`仓库名@commit:仓内相对路径` + 源不随 ACRS 分发声明）；② `validation/README.md` 增补「来源标注可移植性」规则——本机指针住 memory / `~/.acrs/`（与 case-001 F-001 指针模式同源）；规则正文 MUST 自包含，源标注是血缘不是论据。
- **暴露次数**：1（用户指出）。
- **闸门判定**：平台无关——换任何机器 / 任何团队都犯 → Convention（文档协议层）。
- **终态**：**A·Closed**（回链 validation/README 新规则 + 本 README 本体修正）。
